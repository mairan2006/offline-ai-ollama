# ۱) معرفی پروژه

## چیست؟

**هوش مصنوعی آفلاین** یک دستیار فارسی مبتنی بر **Ollama** (موتور مدل محلی) و **Streamlit** (رابط کاربری وب) است. سبک کد از فولدر مرجع DT پیروی می‌کند: پیشوندهای `dt_` / `dtx_`، فایل‌های `*_constants.py`، type hint، و UI راست‌به‌چپ.

## قابلیت‌های اصلی

- چت متنی فارسی با مدل‌های نصب‌شده در Ollama
- کاتالوگ مدل، دانلود در پس‌زمینه، نمایش پیشرفت، انتخاب مدل از سایدبار
- **قانون رم**: قبل از لود هر مدل، رم آزاد چک می‌شود؛ در کمبود، unload مدل قبلی / Whisper
- تاریخچه گفتگو در SQLite (`data/chat_history.db`)
- تحلیل فایل: تصویر، PDF، متن، صوت (بعد از پرامپت کاربر روی پیوست `+`)
- مکالمه صوتی: ضبط → Whisper (STT) → پاسخ مدل → TTS (Edge یا آفلاین ویندوز)
- خروجی JSON هر گفتگو و حذف با دیالوگ تأیید

## قرارداد نام‌گذاری

| پیشوند / الگو | نقش |
|----------------|-----|
| `streamlit_app.py` | نقطهٔ ورود UI |
| `chatbot_*.py` | لایهٔ UI و ثابت‌های فارسی/CSS |
| `dt_*.py` | منطق دامنه (تاریخچه، فایل، TTS، رم، …) |
| `dtx_*.py` | اتصال به سرویس خارجی/موتور (Ollama، Whisper، dotenv) |
| `model_constants.py` | کاتالوگ مدل و آستانه‌های رم |
| `*_constants.py` | ثابت‌ها بدون منطق سنگین |

## وضعیت فازها (خلاصه)

فازهای A تا I پیاده‌سازی شده‌اند: اسکلت چت، مدیریت مدل/رم، تاریخچه، فایل، صوت، TTS آفلاین، UI شبیه Cursor، دکمهٔ `+` برای پیوست فایل. جزئیات تیک‌ها در `PLAN.md` است.

## محدودیت‌ها و بدهی‌های شناخته‌شده

- دقت Whisper فارسی هنوز کامل نیست
- TTS آفلاین فارسی فقط با Voice فارسی ویندوز درست کار می‌کند
- Edge TTS به اینترنت نیاز دارد
- تست کامل همهٔ مسیرهای عکس/PDF و timeout دانلود مدل‌ها هنوز باز است
